# AI 项目管理与任务记录系统

一个基于 Python 的本地 CLI 项目管理与任务记录工具。

## 功能

- 项目 CRUD（创建、查询、更新、删除）
- 任务 CRUD（创建、查询、更新、删除）
- 任务状态与优先级管理
- JSON 文件持久化数据

## 环境要求

- Python 3.12+
- Conda

## 快速开始

```bash
# 创建并激活 conda 环境
conda create -n project_manager python=3.12
conda activate project_manager

# 运行
python -m project_manager.main
```
